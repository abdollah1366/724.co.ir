# ۷۲۴ | سامانه جامع سلامت ساختمان ۷۲۴

وب‌سایت و سامانه نوبت‌دهی ساختمان سلامت ۷۲۴ (724.co.ir)، ساخته‌شده با Django و کاملاً فارسی و راست‌چین.

> وضعیت: **مرحله اول** (بخش‌های خدماتی، پزشکان و نوبت‌دهی اینترنتی، داروخانه و تجهیزات پزشکی با سبد خرید، ثبت‌نام کاربران، باشگاه مشتریان با ژتون و معرفی به دوستان، مشاوره دارویی، فرم تماس، پنل مدیریت).
> معماری و نقشه راه مراحل بعد در [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) آمده است.

## اجرا روی کامپیوتر خودتان (VS Code)

پیش‌نیاز: Python نسخه 3.12 یا بالاتر، Git و VS Code.

۱. دریافت پروژه (در ترمینال VS Code با `` Ctrl+` ``):

```bash
git clone https://github.com/abdollah1366/724.co.ir.git
cd 724.co.ir
code .
```

۲. ساخت محیط مجازی و نصب وابستگی‌ها:

```bash
# ویندوز (PowerShell)
python -m venv .venv
.venv\Scripts\Activate.ps1
# اگر خطای اجرای اسکریپت گرفتید یک بار این را بزنید:
# Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# لینوکس / مک
python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
```

۳. تنظیمات محلی: فایل `.env.example` را با نام `.env` کپی کنید (ویندوز: `copy .env.example .env`، لینوکس/مک: `cp .env.example .env`). مقدار `DJANGO_DEBUG=true` برای توسعه کافی است.

۴. ساخت پایگاه داده، اطلاعات پایه و کاربر مدیر:

```bash
python manage.py migrate
python manage.py seed_services --demo   # بخش‌های خدماتی + پزشکان و محصولات نمونه برای آزمایش
python manage.py createsuperuser
```

۵. اجرای سایت:

```bash
python manage.py runserver
```

سپس در مرورگر باز کنید:
- سایت: http://127.0.0.1:8000
- پنل مدیریت: http://127.0.0.1:8000/admin

در VS Code می‌توانید از منوی **Run and Debug** (کلید `F5`) گزینه «اجرای سایت» یا «اجرای تست‌ها» را هم انتخاب کنید. هنگام باز کردن پروژه، مفسر Python را روی `.venv` بگذارید (`Ctrl+Shift+P` ← *Python: Select Interpreter*).

## کار با پنل مدیریت

- **بخش‌های خدماتی و خدمات**: عنوان، نوع بخش، ترتیب نمایش، ساعات کاری و تعرفه هر خدمت (به ریال).
- **محصولات**: دارو (با اطلاعات علمی: موارد مصرف، مکانیسم اثر، هشدارها، تداخلات و ...)، تجهیزات پزشکی و آرایشی-بهداشتی. قیمت از فهرست محصولات قابل ویرایش است و تاریخچه آن خودکار ثبت می‌شود. **موجودی فقط با اسناد انبار، خرید و فروش تغییر می‌کند** (رسید خرید، سند افتتاحیه یا اضافه انبار). داروهای «نیازمند نسخه» هرگز قابل سفارش آنلاین نیستند.
- **سفارش‌ها**: تأیید، آماده تحویل، «تحویل شد» (فاکتور فروش آنلاین، خروج از انبار و ژتون خودکار) و لغو (برگشت موجودی). لغو و تحویل فقط از اکشن‌های فهرست سفارش‌ها انجام می‌شود.
- **خرید، انبار، فروش و حسابداری**: راهنمای کامل در [docs/ERP.md](docs/ERP.md). اسناد را ذخیره و سپس «ثبت نهایی» کنید؛ سند نهایی قابل ویرایش و حذف نیست و اصلاح با «برگشت سند» انجام می‌شود.
- **آزمایشگاه**: راهنمای کامل در [docs/LAB.md](docs/LAB.md). پیشخوان آزمایشگاه در `/lab/staff/`، کیوسک نوبت در `/lab/queue/kiosk/` و نمایشگر سالن انتظار در `/lab/queue/display/` است. برای گردش نمونه: `python manage.py lab_demo --password "یک-رمز-قوی"` (فقط پایگاه داده آزمایشی).
- **مشاوره‌های دارویی**: پاسخ داروساز را بنویسید تا در «حساب من» کاربر نمایش داده شود.
- **اعضای باشگاه، تراکنش‌های ژتون و جوایز**: مشاهده مانده و سطح؛ تعریف جوایز و ژتون لازم؛ در «جوایز دریافت‌شده» کد جایزه را جست‌وجو کنید و «استفاده شد» یا «لغو و برگرداندن ژتون» بزنید. تعداد ژتون هر خدمت در `CLUB_RULES` و سطح‌ها در `CLUB_LEVELS` در `config/settings.py` است.
- **پزشکان**: شماره نظام پزشکی الزامی است. برنامه حضور هفتگی داخل صفحه هر پزشک تعریف می‌شود و زمان‌های نوبت خودکار ساخته می‌شوند.
- **نوبت‌ها**: مشاهده، جست‌وجو، تأیید، «انجام شد» (ژتون خودکار) یا لغو گروهی.
- **پیام‌های تماس**: پیام‌های رسیده از فرم تماس.

برای دیدن گردش کامل داروخانه روی یک پایگاه داده آزمایشی: `python manage.py erp_demo --password "یک-رمز-قوی"` و سپس ورود با `demo-manager` یا `demo-pharmacist` و رفتن به `/backoffice/`. این دستور را روی پایگاه داده واقعی اجرا نکنید.

پیش از انتشار واقعی، پزشکان و محصولات نمونه (نامک‌هایی که با `demo-` شروع می‌شوند) را از پنل حذف کنید.

## نکات امنیتی

- فایل `.env` و `db.sqlite3` هرگز نباید وارد گیت شوند (در `.gitignore` هستند).
- در سرور واقعی: `DJANGO_DEBUG=false`، یک `DJANGO_SECRET_KEY` طولانی و تصادفی، `DJANGO_ALLOWED_HOSTS=724.co.ir,www.724.co.ir`، پایگاه داده PostgreSQL و HTTPS الزامی است. آدرس پنل مدیریت را هم با `DJANGO_ADMIN_URL` تغییر دهید.
